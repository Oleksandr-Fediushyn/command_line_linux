# Практикум: Основи командного рядка Linux

## Підготовка до роботи
1. Відкрийте термінал у нижній частині екрана (якщо його не видно, натисніть `Ctrl + ~` або у верхньому меню оберіть **Terminal -> New Terminal**).
2. Переконайтеся, що ви знаходитесь у домашній директорії за допомогою команди `pwd`.

---

## Блок 1. Навігація та структура каталогів (15 хв)
*Мета: навчитися створювати вкладені директорії та візуалізувати дерево файлів.*

1. Створіть у поточній директорії робочу папку `lab_linux` і перейдіть у неї.
2. Однією командою (використовуючи прапорець `-p`) створіть наступну структуру каталогів:
   * `project/src`
   * `project/docs`
   * `project/logs`
   * `project/backup`
3. Перевірте створену структуру візуально за допомогою встановленої утиліти `tree` (виконайте `tree project`).
4. Перейдіть у папку `project/logs` і створіть три порожні файли: `app.log`, `error.log`, `access.log`.

---

## Блок 2. Робота з текстом та конвеєрами (20 хв)
*Мета: навчитися генерувати текстові дані, фільтрувати їх та перенаправляти потоки виводу.*

1. Запишіть список усіх процесів, що зараз запущені в системі, у файл `project/logs/app.log` (використайте команду `ps aux` та оператор перенаправлення `>`).
2. За допомогою команди `grep` знайдіть у файлі `app.log` усі рядки, що містять слово `bash` або `root`, і допишіть результат у файл `error.log` (використайте оператор `>>`).
3. Виведіть на екран перші 5 рядків файлу `app.log` (команда `head`), а потім останні 5 рядків (команда `tail`).
4. Порахуйте загальну кількість рядків у файлі `app.log` за допомогою утиліти `wc -l`.
5. **Завдання із зірочкою:** виведіть список усіх файлів у системній директорії `/etc`, відсортуйте їх у зворотному порядку і збережіть перші 10 результатів у файл `project/docs/etc_top10.txt` (використайте конвеєр `|`).

---

## Блок 3. Права доступу та створення скрипту (20 хв)
*Мета: розібратися з правами доступу `chmod` та написати простий bash-скрипт.*

1. У папці `project/src` створіть файл `sysinfo.sh` за допомогою редактора `nano` (або `vim`).
2. Додайте у файл наступний код, який виводить поточну дату, ім'я користувача та вільне місце на диску:
   ```bash
   #!/bin/bash
   echo "=== Звіт про систему ==="
   echo "Дата: \$(date)"
   echo "Користувач: \$(whoami)"
   echo "Дисковий простір:"
   df -h /
   ```
3. Спробуйте запустити скрипт командою `./sysinfo.sh`. Поясніть, чому система видає помилку `Permission denied`.
4. Надайте файлу права на виконання для власника (`chmod u+x sysinfo.sh` або `chmod 755 sysinfo.sh`) та запустіть його ще раз.
5. Скопіюйте скрипт у папку `project/backup` під назвою `sysinfo_old.sh`.

---

## Блок 4. Моніторинг системи та мережі (15 хв)
*Мета: ознайомитися з системними утилітами діагностики.*

1. Запустіть інтерактивний монітор процесів `htop`. Визначте, скільки оперативної пам'яті виділено цьому контейнеру. Для виходу натисніть `F10` або `q`.
2. Перевірте мережеві інтерфейси та IP-адресу вашого контейнера за допомогою команди `ifconfig` або `ip a`.
3. Проскануйте локальний хост (`127.0.0.1`) на наявність відкритих портів за допомогою утиліти `nmap`.
4. Запустіть файловий менеджер Midnight Commander (`mc`), знайдіть створену вами папку `lab_linux` та перегляньте вміст файлу `sysinfo.sh` через вбудований переглядач (`F3`). Вихід — `F10`.
